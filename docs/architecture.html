Factory Inventory Management

Full-stack application with Vue 3 frontend, Python FastAPI backend, and in-memory mock data

System Architecture

Tech Stack

Frontend

  • Vue 3
  • Composition API
  • Vue Router 4
  • Vite 8
  • Axios

Backend

  • Python 3.13
  • FastAPI
  • Pydantic
  • Uvicorn
  • uv

Data

  • inventory.json
  • orders.json
  • spending.json
  • backlog_items.json
  • demand_forecasts.json

API Endpoints

GET /api/inventory warehouse, category
GET /api/orders warehouse, category, status, month
GET /api/dashboard/summary all filters
GET /api/demand none
GET /api/backlog none
GET /api/spending/* summary, monthly, categories
GET /api/reports/* quarterly, monthly-trends

Project Structure

inventory-management/
client/
src/
api.js — Centralized API client
views/ — Dashboard, Inventory, Orders, Backlog, Demand, Spending, Reports
components/ — FilterBar, Modals, ProfileMenu
composables/ — useFilters, useAuth, useI18n
server/
main.py — FastAPI endpoints & Pydantic models
mock_data.py — JSON file loader
data/ — JSON data files
tests/
backend/ — pytest + FastAPI TestClient
